# Customer Behaviour Analysis

## Overview
This project analyzes customer purchasing behavior using Python, SQL, and Power BI. The objective is to identify customer trends, purchasing patterns, and business insights that can help improve decision-making.

## Dataset
The dataset contains customer information, including:
- Customer ID
- Age
- Gender
- Purchase Amount
- Product Category
- Location
- Payment Method
- Shipping Type
- Review Rating
- Subscription Status

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQL (MySQL / SQL Server / PostgreSQL)
- Power BI
- Excel
- Jupyter Notebook

## Project Workflow

### 1. Data Loading
- Imported dataset into Python.
- Explored data structure and column information.

### 2. Data Cleaning
- Checked missing values.
- Handled null values.
- Removed duplicates.
- Corrected data types.

### 3. Exploratory Data Analysis (EDA)
- Customer demographics analysis.
- Purchase behavior analysis.
- Category-wise sales analysis.
- Payment method analysis.
- Shipping preference analysis.

### 4. SQL Analysis
Sample analyses performed:
- Total sales by category.
- Average purchase amount by gender.
- Top spending customers.
- Subscription analysis.
- Shipping type comparison.

### 5. Power BI Dashboard
Created an interactive dashboard containing:
- Total Sales KPI
- Customer Count KPI
- Sales by Category
- Sales by Gender
- Payment Method Distribution
- Shipping Type Analysis
- Customer Segmentation

## Key Insights
- Identified top-performing product categories.
- Analyzed customer spending patterns.
- Evaluated preferred payment methods.
- Compared shipping methods and purchase behavior.
- Generated actionable business recommendations.

## Results
The analysis provides valuable insights into customer preferences and purchasing behavior, helping businesses improve marketing strategies and customer engagement.
